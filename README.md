## About

This is my personal portfolio: a fast, single-page site that presents my experience, selected work, teaching and skills.

## Highlights

- **Light and dark themes** that follow the visitor's system setting and remember their choice.
- **Animated background** with a network of travelling light pulses, soft gradients and a cursor spotlight.
- **Motion that respects the visitor:** sections reveal on scroll and the stats count up, and everything stays still for visitors who prefer reduced motion.
- **Downloadable CV** generated from the same content as the site.
- **Built for sharing and search,** with a custom link-preview image and structured data.
- **Accessible and responsive,** from phone width up.

## Built with

[Astro](https://astro.build), plain CSS, TypeScript and the Canvas API, hosted on GitHub Pages.
